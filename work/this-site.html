About

Hand-written HTML and CSS, no framework, no build step. The hero is a Clifford attractor drawn live in WebGL2 from the same maths as the Fractal MCP renders; it pauses if you ask it to, or if your system prefers reduced motion. The fonts are served from the site, not from Google. The only script from elsewhere is a cookie-free visitor counter.

It was built in Claude Code with a design skill I keep, and checked in headless Chrome at desktop and phone widths before each push.

What I did

  • Briefed and directed the build, then rewrote the copy by hand after the first version read like a brochure.
  • Took every screenshot from demo modes with made-up data, so nothing private is on the page.
  • Rebuilt one screen of Talent Radar as a small page of plain HTML and JavaScript, with made-up people and redacted signals, so you can click around it instead of looking at a picture.
