MetaLoL

A new front end for a public League of Legends stats site, the sister of MetaTFT.

Status
On a branch, awaiting the owner’s review
Stack
React 19, TypeScript, Vite

About

MetaLoL is a public stats site for League of Legends, run by the same person as MetaTFT, one of the main stats sites for Teamfight Tactics. I contribute under my own GitHub account. In 2025 I made small fixes to the champion page on the live site. In September 2026 I started a ground-up remake of the front end on a branch: a new look, a tier list, champion pages, a header champion finder, a phone layout and a test suite.

The owner has not reviewed it yet, so it is not live.

What I did

  • Mapped the three repos (front end, API, crawler) and reported two security problems to the owner, who fixed them.
  • Rebuilt the front end against the live API: tier list, champion pages, matchup views, header search, page titles and metadata.
  • Checked the phone layout at real sizes. No sideways scroll at 390 pixels.
  • Typecheck, lint, 31 tests and a production build all pass.

Stack

  • React 19 and TypeScript
  • Vite, with a test suite
  • Working against someone else’s API and data without cluster access
  • Claude Code for the build

Skills

  • Working in someone else’s codebase, to their conventions
  • Front-end design that reads well on a phone
  • Finishing: tests, titles and metadata, not just the pretty parts
  • Reporting a problem to an owner clearly and leaving the fix to them
