A harness for Claude Code

Everything I built around Claude Code so it works like a colleague who remembers.

Status
In daily use since 21 October 2026
Stack
Node 24 with no npm packages, SQLite, Claude Code hooks, Ollama

About

Claude Code forgets everything between sessions, runs several sessions at once that can trample each other, and quietly burns through a capped plan. This is the layer I built around it: small programs that run before and after each step the AI takes, notes per project that get fed back in, and a dashboard.

I built it on my own from 21 October 2026, in Claude Code, and it has run every working day since. Two other projects on this site, the local-model server and the fractal server, plug into it.

What it does

  • Memory. Every project has notes: brief, state, decisions, log. The right ones are injected the moment I mention the project.
  • Write-ups. When a session ends, the transcript becomes a log entry, a fresh state, dated decisions and a git commit. 187 so far, none by hand.
  • Guards. Before every command and edit: no reading secrets or real-data folders, no git commands that throw away work, no keys written into files.
  • Review. A read-only bot reviews every commit and pull request for bugs and scores it. 94 reviews so far.
  • Planning. The expensive model writes the plan once; cheaper models build it step by step, each step checked.
  • Several sessions at once. Each one knows who else is editing what. The first clash on a file is stopped once, with who and why.
  • Local models. Long files and private data go to a model on my graphics card; only the answer comes back.
  • Voice. Local speech recognition. I talk to a session from across the room and the reply is read aloud. Nothing goes to a cloud speech service.
  • Day planner. A local model slots my tasks into free time on my calendar. The hard rules are code.
  • Dashboard. Projects, health checks, reviews, tasks and usage, from my phone over a private network.
  • Usage. Tracks the plan limits and forecasts when they will run out, with cost per subagent.
  • Backups. Nightly, with an encrypted copy off the machine, and uncommitted work snapshotted between commits. Built, restore not yet proven on a real repo.
  • Team feed. Change notes from my sessions reach my partner’s sessions on our shared project.

Stack

  • Node 24 with zero dependencies (node:sqlite, node:http)
  • Claude Code hooks on ten events
  • Ollama running Gemma for the local jobs
  • whisper.cpp and Kokoro for voice
  • A vanilla JavaScript dashboard, no build step

Skills

  • Designing a system rather than a script: 49 modules that fit together
  • Safety first: guards, read-only reviewers, nothing secret in the AI’s context
  • Cost awareness: cheap models for cheap work
  • Writing things down so the next session, or a colleague, can pick up where I left off
