Local models for Claude

Two small servers that let Claude Code use a model on my own graphics card.

Status
Running daily
Stack
Node, MCP, Ollama, Gemma

About

Claude Code has a context limit and a paid plan. Logs, data dumps and long documents eat both. This gives Claude three tools: ask (a question to a local model), list_models, and digest (hand a set of files to a local model with one question and get back only the answer, with file and line references). The files never enter Claude’s context, so private data stays on the machine and the paid context stays small.

A second copy of the server lets another machine use my graphics card over a private network.

What I did

  • Specified the three tools and had Claude Code build the servers in Node with the MCP SDK.
  • Wired digest into my harness, so any session can read a 12 MB log in one call.
  • Tuned the prompt so answers cite file and line, which makes them checkable.

Stack

  • Node and the MCP SDK
  • Ollama running Gemma on an RTX 5070 Ti
  • zod for argument validation

Skills

  • Knowing which work belongs on a cheap local model
  • Keeping private data off cloud services
  • Small, finished tools rather than platforms
