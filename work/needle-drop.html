Needle Drop

A keyboard DJ rhythm game with roguelike runs, in Godot.

Status
In progress, started November 2026
Stack
Godot 4.7, GDScript, Python for the music

About

Left hand on WASD does the mixing: bass in and out, crossfader. Right hand on the arrow keys lines up the next record and, when a record drops, plays a short falling-arrow dance section. Every record switch scores like a card game, chips times multiplier: the key relationship between the two records, a locked tempo, hitting the switch on the one, crowd energy. Between sets a shop sells records, perks and bigger rigs.

The music is synthesised by a script, so every track has an exact tempo and key and nothing is licensed. The design is written, about 7,000 words plus an engineering contract that lets several build passes run in parallel, and the first playable slice is being built now. No screenshots yet.

What I did

  • Designed the core loop and the scoring, and wrote it all down before building anything.
  • Split the first slice into work packages with a shared contract, so parallel Claude builds do not collide.
  • Set the rules for the build: scene-first Godot, tunables as exported properties, no licensed audio.

Stack

  • Godot 4.7 and GDScript
  • Python to synthesise the records: exact BPM and key, stems for kick, drums, bass and music
  • A scene-first workflow for Godot and Claude that my brother wrote

Skills

  • Game design: writing a loop down tightly enough to build
  • Scoping: a first slice before any of the fun extras
  • Coordinating parallel AI builds through a written contract
