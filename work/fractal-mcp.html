Fractal MCP

A render farm for maths art that Claude can call like a tool.

Status
Running as a Windows service
Stack
Node, Python, OpenCL, MCP, Mandelbulber 2, Fraktaler 3

About

Fractal MCP is a server on my PC that exposes the renderers I have collected (Mandelbulber 2, Fraktaler 3, a three-body simulator, a Clifford attractor engine, a nebulabrot renderer) as tools Claude can call. I ask for a picture in a sentence, Claude picks the tool and the parameters, the GPU renders it, and the image comes back into the conversation.

The server is token-protected and set up so two friends can point their own Claude at it. Every render on the home page came out of it, and the live hero runs the same three-body maths in your browser.

What I did

  • Chose and installed the renderers, and had Claude Code wrap each one as a tool with safe parameters: no file paths, one GPU job at a time, output confined to one folder.
  • Built the three-body and Clifford renderers in Python and OpenCL, including the palettes.
  • Wrote the hand-over page so friends could set it up.
  • Brought the three-body maths to WebGL for this site’s live hero.

Stack

  • Node and the MCP SDK
  • Python with OpenCL and moderngl on the GPU
  • Mandelbulber 2 and Fraktaler 3 driven from the command line
  • WebGL2 for the browser version

Skills

  • Turning a vague wish into parameters and a finished image
  • Running a service safely on a home network
  • Judgement: knowing when a render is finished and when it is not worth keeping
